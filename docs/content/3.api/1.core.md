Compile a block from your own code, such as a build step for another
bundler.

```ts
import { compileBlock, compileBlockOrThrow, TailwindBlockError } from 'vue-tailwind-block'
```

## `compileBlock`

Compiles the content of a block. It returns the problems of an invalid
block instead of throwing.

```ts [check-block.ts]
import { compileBlock } from 'vue-tailwind-block'

const result = compileBlock('root:\n  - inline-flex items-center\n  - px-4', { lang: 'yaml' })

if (result.ok) {
  result.classTree.root // 'inline-flex items-center px-4'
} else {
  for (const problem of result.problems) {
    console.error(problem.message)
  }
}
```

::field-group
:::field{name="content" type="string" required}
The block content, without its tags.
:::

:::field{name="options" type="CompileOptions"}
The `lang` attribute of the block, as `{ lang }`. See [Types](#types).
:::
::

The result is a [`CompileResult`](#types). Check `ok` before reading
`classTree` or `problems`.

## `compileBlockOrThrow`

Compiles the same way, returns the class tree, and throws a
[`TailwindBlockError`](#tailwindblockerror) when the block is invalid.

```ts [build-step.ts]
import { compileBlockOrThrow } from 'vue-tailwind-block'

const classTree = compileBlockOrThrow('root: rounded-lg border p-6')
// { root: 'rounded-lg border p-6' }
```

It takes the same `content` and `options` as `compileBlock`.

## `TailwindBlockError`

Thrown by `compileBlockOrThrow`. `problems` holds every problem in the
block:

```ts [build-step.ts]
import { compileBlockOrThrow, TailwindBlockError } from 'vue-tailwind-block'

try {
  compileBlockOrThrow('variants:\n  solid:\n')
} catch (error) {
  if (error instanceof TailwindBlockError) {
    error.problems[0].message
    // 'Expected a class string, list or group at variants.solid, got null'
  }
}
```

## Types

::field-group
:::field{name="CompileOptions" type="{ lang?: string }"}
The `lang` attribute of the block. `'yaml'`, `'yml'` and `undefined`
compile. Any other value is a problem covering the whole block.
:::

:::field{name="CompileResult" type="{ ok: true, classTree } | { ok: false, problems }"}
What `compileBlock` returns.
:::

:::field{name="ClassTree" type="{ [key: string]: string | ClassTree }"}
A compiled block. Lists are joined into one string, and nested keys
become nested objects.
:::

:::field{name="BlockProblem" type="{ message: string, start: number, end: number }"}
One reason a block does not compile. `start` and `end` are offsets into
the block content, not into the `.vue` file. A problem that covers the
whole block starts at `0`.
:::

:::field{name="TailwindBlockOptions" type="{ binding?: string }"}
The options of the Nuxt module, the Vite plugin and the editor plugin.
See [Configuration](/getting-started/configuration).
:::
::

::collapsible{name="type definitions"}
```ts
interface CompileOptions {
  lang?: string
}

type CompileResult =
  | { ok: true, classTree: ClassTree }
  | { ok: false, problems: BlockProblem[] }

interface ClassTree {
  [key: string]: string | ClassTree
}

interface BlockProblem {
  message: string
  start: number
  end: number
}

class TailwindBlockError extends Error {
  readonly problems: BlockProblem[]
}

interface TailwindBlockOptions {
  binding?: string
}
```
