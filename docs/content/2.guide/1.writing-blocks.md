## Keys

Each key names a part of the component, and its value holds the classes
for that part. The template reads them from `classes`:

```vue [Button.vue]
<template>
  <button :class="classes.root">
    <slot />
  </button>
</template>

<tailwind lang="yaml">
root: inline-flex items-center gap-2 rounded-md px-4 py-2 text-sm
</tailwind>
```

::note
`lang` can be `yaml`, `yml` or left out. Prefer `yaml`, because VS Code
highlights the block as YAML only then. A component holds one block.
::

## Lists

A list is joined into one class string, with each entry trimmed. Use one
when the classes no longer fit on a line:

::code-group
```yaml [Button.vue]
root:
  - inline-flex items-center gap-2 rounded-md px-4 py-2 text-sm
  - disabled:pointer-events-none disabled:opacity-50
  - focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-sky-500
```

```ts [Compiled]
classes.root
// 'inline-flex items-center gap-2 rounded-md px-4 py-2 text-sm disabled:pointer-events-none disabled:opacity-50 focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-sky-500'
```
::

## Comments

A `#` after a space starts a comment, on its own line or after an entry:

```yaml [Button.vue]
root:
  - inline-flex items-center gap-2 rounded-md px-4 py-2 text-sm
  # without pointer-events-none, a disabled button still shows hover styles
  - disabled:pointer-events-none disabled:opacity-50
```

A `#` written straight after a class is part of the class.

## Groups

A key can hold other keys instead of classes, to any depth. The template
picks an entry from each group with its props:

```vue [Button.vue]
<script setup lang="ts">
defineProps<{
  variant: 'solid' | 'outline'
  size: 'sm' | 'lg'
}>()
</script>

<template>
  <button :class="[classes.root, classes.variants[variant], classes.sizes[size]]">
    <slot />
  </button>
</template>

<tailwind lang="yaml">
root: inline-flex items-center gap-2 rounded-md text-sm
variants:
  solid: bg-sky-600 text-white hover:bg-sky-500
  outline: border border-zinc-300 hover:bg-zinc-50
sizes:
  sm: h-8 px-3
  lg: h-10 px-6
</tailwind>
```

`root`, `variants` and `sizes` are ordinary names. Name the groups after
the parts of your component, such as `icon` or `label`.

## Quoting

Classes need no quotes, even with characters YAML treats as syntax, such
as `!`, `@`, `*`, `[` and `&`:

```yaml
root:
  - "!bg-red-500 *:rounded-md"
  - @container/card:p-4
  - [&>svg]:size-4 w-[calc(100%-1rem)]
  - bg-[color:var(--brand)]/10
```

Quoted entries, like the first one, work too.

::warning
Quote an entry that contains ` #`. Otherwise the comment cuts the entry
off.
::

Flow lists (`[a, b]`), anchors, aliases and `<<` merge keys are read as
plain text. Write each entry on its own line.

## Errors

Every value must be a string, a list of strings or a group of keys.
Anything else fails the build with an error that names the key:

::code-group
```yaml [Button.vue]
variants:
  solid:
  outline: border border-zinc-300 hover:bg-zinc-50
```

```text [Build error]
Expected a class string, list or group at variants.solid, got null
```
::

YAML syntax errors and a `lang` other than `yaml` or `yml` fail the build
too.
