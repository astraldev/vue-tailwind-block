A project needs two pieces: the build plugin, which turns each block into
`classes`, and the editor plugin, which tells the editor and `vue-tsc`
what `classes` holds. In Nuxt, the module sets up both.

## Requirements

- Vue 3.3 or newer
- Nuxt 3.10 or newer, or Vite 5 or newer
- Tailwind CSS v3 or v4
- `vue-tsc` and the Vue extension 3.2 or newer, for editor types
- ESLint 9 or 10 with flat config, for [linting](/guide/linting)

## Install

::tabs
:::tabs-item{label="Nuxt" icon="i-simple-icons-nuxt"}
::::steps
### Add the package

:::::code-group
```bash [pnpm]
pnpm add -D vue-tailwind-block
```

```bash [npm]
npm install -D vue-tailwind-block
```

```bash [yarn]
yarn add -D vue-tailwind-block
```

```bash [bun]
bun add -D vue-tailwind-block
```
:::::

### Register the module

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  modules: ['vue-tailwind-block/nuxt'],
})
```

The module also adds the editor plugin to the `tsconfig` Nuxt generates.
Run `nuxt prepare`, or start the dev server once, then reload the editor
window so it picks the plugin up.

### Register the plugin

```ts [vite.config.ts]
import tailwindcss from '@tailwindcss/vite'
import vue from '@vitejs/plugin-vue'
import { defineConfig } from 'vite'
import tailwindBlock from 'vue-tailwind-block/vite'

export default defineConfig({
  plugins: [tailwindBlock(), vue(), tailwindcss()],
})
```

### Add the editor types

Add the editor plugin to the `tsconfig` that includes your `.vue` files.
In a `create-vue` project, that is `tsconfig.app.json`.

```json [tsconfig.app.json]
{
  "vueCompilerOptions": {
    "plugins": [{ "name": "vue-tailwind-block/volar" }]
  }
}
```

Reload the editor window once, so the language server loads the plugin.

## Tailwind CSS v3

Tailwind v3 only scans the files listed in `content`. Include your
`.vue` files:

```js [tailwind.config.js]
export default {
  content: ['./index.html', './src/**/*.vue'],
}
```

## Tailwind CSS IntelliSense

The [Tailwind CSS IntelliSense](https://marketplace.visualstudio.com/items?itemName=bradlc.vscode-tailwindcss){target="_blank"}
extension does not look inside the block by default. Add this setting to
get hover, completion and color swatches for the classes in it:

```json [.vscode/settings.json]
{
  "tailwindCSS.experimental.classRegex": [
    ["<tailwind[^>]*>([\\s\\S]*?)</tailwind>", "(?:^|\\n)[ \\t]*(?:-[ \\t]+|[^\\s:#\"'][^:\\n]*:[ \\t]+)[\"']?([^\\n#\"']+)"]
  ]
}
```

## Verify

Add a block to any component and use `classes` in its template:

```vue [Card.vue]
<template>
  <div :class="classes.root">
    <slot />
  </div>
</template>

<tailwind lang="yaml">
root: rounded-lg border p-6 shadow-sm
</tailwind>
```

The card renders with a border and a shadow. If the editor underlines
`classes` as undefined, the editor plugin is not loaded.
